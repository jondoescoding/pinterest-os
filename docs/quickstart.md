# Quickstart

Pinterest OS plans content and schedules Pinterest posts through [Postiz](integrations/postiz.md).

## Before changing code

1. Read [Architecture](architecture.md) for ownership and boundaries.
2. Read the relevant [workflow](index.md#workflows) or [integration](index.md#integrations).
3. Follow [Development](development.md) and run `pnpm typecheck`.
4. For UI changes, follow [Design standards](design/design-standards.md).
5. Store generated evidence according to [Artifact organization](operations/artifacts.md).

## Knowledge maintenance

Update the smallest existing concept page when behavior changes. Add a new page only for a distinct durable concept, then link it from [the index](index.md) and related pages.
